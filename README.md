# myTischtennis-Auswertung – öffentliche Webseite

Diese Veröffentlichung enthält ausschließlich die schreibgeschützte Weboberfläche und die verschlüsselte Ergebnisdatei. Die Browser-Erweiterung und die Entwicklungsdateien bleiben im privaten Repository.

Die Webseite wird über GitHub Pages veröffentlicht. Zum Anzeigen der Ergebnisse ist die beim Erzeugen der Datei verwendete Passphrase erforderlich.
